# 配置模板

这些文件只提供结构，不包含任何人的简历、联系方式、岗位意向、目标城市或毕业届别。

首次打开客户端时，程序会把模板复制到本机的 `data/boss-agent/`，已有文件不会被覆盖：

- `preferences.example.json` → `preferences/settings.json`
- `profile.example.json` → `resumes/user.json`

在客户端的“筛选条件”和“个人资料”页面填写并保存。城市、岗位方向、毕业届别和薪资下限初始为空；只有完成筛选配置后才能生成新批次。批次数量和读取预算是通用运行参数，可按需修改。

不要把真实资料写进本目录中的模板。运行数据与密钥保存在被 Git 忽略的本机目录中。
