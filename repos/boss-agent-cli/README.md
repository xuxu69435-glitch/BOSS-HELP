# BOSS-HELP 源码包

这是 BOSS-HELP 的 Python 源码、网页资源、Chrome 扩展与测试目录。

完整中文安装、配置、隐私说明与使用流程见仓库根目录的 [README](../../README.md)。从根目录运行 `安装环境.bat`，不要向系统 Python 安装依赖。

城市、岗位方向、毕业届别和个人资料由使用者在本机自行配置。测试中的岗位、城市、届别与联系字段为测试输入，不代表项目维护者的个人资料或求职意向。

本源码基于 [boss-agent-cli](https://github.com/can4hou6joeng4/boss-agent-cli)，保留上游 [MIT 许可](LICENSE) 与第三方资源许可。
